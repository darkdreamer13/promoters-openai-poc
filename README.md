# Promoters OpenAI Realtime PoC

Εσωτερικό browser PoC για ελληνική φωνητική συνομιλία με OpenAI Realtime. Χρησιμοποιεί WebRTC· δεν απαιτεί SIP αριθμό και δεν ενσωματώνει τηλεφωνικό routing, PBX, ημερολόγιο, CRM ή ανθρώπινη μεταφορά.

## Τοπική δοκιμή

- Απαιτούνται Node.js 20+ και project API key με ενεργό API billing και πρόσβαση στο `gpt-realtime-2.1`.
- Τρέξε `./start.sh`. Την πρώτη φορά δημιουργεί το `.env.local`.
- Συμπλήρωσε στο `.env.local` το `OPENAI_API_KEY` και έναν ιδιωτικό, τυχαίο `POC_ACCESS_CODE`. Μην προσθέσεις αυτό το αρχείο στο Git.
- Τρέξε ξανά `./start.sh` και άνοιξε `http://127.0.0.1:3333`.
- Επίτρεψε πρόσβαση στο μικρόφωνο, πληκτρολόγησε τον κωδικό δοκιμής και πάτησε «Έναρξη συνομιλίας».

## Build και Vercel

Το `npm run build` ελέγχει τα αρχεία της σελίδας, τις ρυθμίσεις Vercel και τη διαμόρφωση του ελληνικού PoC. Στο Vercel πρέπει να οριστούν τα `OPENAI_API_KEY` και `POC_ACCESS_CODE` ως Environment Variables και μετά να γίνει redeploy. Το OpenAI key παραμένει server-side. Χωρίς αυτές τις ρυθμίσεις το deployment σερβίρει τη σελίδα αλλά δεν ανοίγει συνεδρίες.

## Δεδομένα και κόστος

Το browser συνδέεται απευθείας στο OpenAI Realtime μέσω WebRTC. Ο server δημιουργεί την απάντηση SDP και δεν καταγράφει ή αποθηκεύει ήχο ή transcript. Η σελίδα κρατά τη συνομιλία και τα usage events μόνο στη μνήμη της καρτέλας· ο χρήστης επιλέγει αν θα εξάγει JSON ή CSV. Χρησιμοποίησε μόνο φανταστικά δεδομένα.

Η εκτίμηση τιμών χρησιμοποιεί το `gpt-realtime-2.1` και `gpt-4o-mini-transcribe`. Η μετατροπή EUR είναι ενδεικτική (1 EUR ≈ 1.13 USD). Οι τελικές χρεώσεις επιβεβαιώνονται στο OpenAI Usage dashboard. SIP/τηλεφωνία, φόροι και λοιπή υποδομή εξαιρούνται. Η browser δοκιμή δεν επαληθεύει SIP, PBX, caller ID ή transfer.

## Promoters voice profile

Το υπάρχον PoC έχει ένα προσωρινό, hardcoded Promoters test profile στο `lib/assistant-instructions.mjs`: φυσικός χαιρετισμός, έξι κατηγορίες υπηρεσιών, περιοχές εξυπηρέτησης, ελληνικά/αγγλικά, δωρεάν συνεδρία μίας ώρας, πολιτική τιμών και εγκεκριμένα στοιχεία επικοινωνίας. Χρησιμοποιεί μόνο συνθετικά στοιχεία για δοκιμές αιτήματος επανεπικοινωνίας. Δεν αποθηκεύει πραγματικά leads, δεν κλείνει ραντεβού και δεν κάνει transfer. Η περιγραφή υπηρεσιών και οι ισχυρισμοί αποτελέσματος παραμένουν σε υψηλό επίπεδο μέχρι να επικαιροποιηθούν οι πρωτογενείς πηγές. Το προφίλ είναι ρύθμιση μόνο του PoC, όχι backend ή tenant configuration.
